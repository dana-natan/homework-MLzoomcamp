## STUDY PROTOCOL (repeat for each module)
1. **Preview (15 minutes):** Read homework and identify deliverables.
2. **Attempt (45–60 minutes):** Write your own code before viewing a solution.
3. **Targeted learning (20–40 minutes):** Watch only the exact relevant lesson(s).
4. **Apply:** Implement, evaluate, explain what worked and why.
5. **Finish:** Restart and run all, commit, push, submit, mark done.

**Stuck rule:** After 20 minutes, write: expected result, actual result, error, and what you tried. Ask for a hint, not a full solution.
